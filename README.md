# Portefolio-Matthieu_Tremblay

Voici mon portfolio où vous pourrez en apprendre davantage sur moi en quelques mots et découvrir les projets sur lesquels j'ai travaillé depuis 2022.

---

## 🛠️ Technologies utilisées

### Framework & Build
| Technologie | Rôle |
|---|---|
| [React 18](https://react.dev/) | Framework JavaScript principal (composants, routing) |
| [Vite](https://vitejs.dev/) | Outil de build et serveur de développement |
| [React Router DOM](https://reactrouter.com/) | Navigation côté client (SPA) |

### 3D & Animations
| Technologie | Rôle |
|---|---|
| [Three.js](https://threejs.org/) | Moteur de rendu 3D WebGL |
| [React Three Fiber](https://docs.pmnd.rs/react-three-fiber) | Intégration de Three.js dans React |
| [React Three Drei](https://github.com/pmndrs/drei) | Utilitaires et helpers pour React Three Fiber |
| [Framer Motion](https://www.framer.com/motion/) | Animations déclaratives des composants React |
| [React Parallax Tilt](https://github.com/mkosir/react-parallax-tilt) | Effet de tilt 3D sur les cartes |
| [Maath](https://github.com/pmndrs/maath) | Utilitaires mathématiques pour la 3D |

### Styles
| Technologie | Rôle |
|---|---|
| [Tailwind CSS](https://tailwindcss.com/) | Framework CSS utilitaire |
| [PostCSS](https://postcss.org/) | Transformation du CSS |
| [Autoprefixer](https://github.com/postcss/autoprefixer) | Compatibilité navigateurs (préfixes CSS) |

### UI / Composants
| Technologie | Rôle |
|---|---|
| [React Vertical Timeline Component](https://github.com/stephane-monnot/react-vertical-timeline) | Affichage de la timeline des expériences |
| [EmailJS](https://www.emailjs.com/) | Envoi d'emails depuis le formulaire de contact |

---

## 🗂️ Structure du projet

```
project_3D_developer_portfolio/
├── public/           # Ressources statiques (modèles 3D, images)
├── src/
│   ├── assets/       # Images et icônes
│   ├── components/   # Composants React (Navbar, Hero, About, etc.)
│   ├── constants/    # Données statiques (expériences, projets, technologies)
│   ├── contexts/     # Contextes React (langue FR/EN)
│   ├── hoc/          # Higher-Order Components
│   ├── translations/ # Fichiers de traduction FR/EN
│   └── utils/        # Fonctions utilitaires
├── index.html
├── package.json
├── tailwind.config.cjs
└── vite.config.js
```
